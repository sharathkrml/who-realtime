# AGENTS.md

Conventions for agents working in this repo. `CLAUDE.md` is a symlink to this file.

## What this is

A macOS app that records a meeting (process audio tap + mic, or mic only), transcribes
on device with **Voz**, and labels speakers with **Who** (both from `desert-ant-core`).

Two app flavors on one shared library:

| Target | Product | Notes |
|---|---|---|
| `WhoRealtime` | library | capture, attribution, doc, all SwiftUI views |
| `WhoMenuBar` | `build/WhoRealtime.app` | `MenuBarExtra`, `LSUIElement` (no Dock icon) |
| `WhoWindowed` | `build/WhoRealtime Windowed.app` | regular `Window` scene, ⌘R |
| `WhoTapCore` | ObjC shim | Core Audio process-tap creation |
| `WhoRealtimeTests` | tests | Swift Testing (`@Test`), not XCTest |

- Swift 6.2, `swift-tools-version: 6.2`, macOS 15+, SwiftPM — **no Xcode project / XcodeGen**.
- All code is main-actor by default (`.defaultIsolation(MainActor.self)`); opt out explicitly,
  don't add `@MainActor` everywhere.
- 4-space indent, no tabs.

## Build, test, run

```sh
swift build
swift test
scripts/make-app.sh          # release build + .app bundles with generated Info.plist
scripts/make-dmg.sh          # apps + build/WhoRealtime.dmg
open build/WhoRealtime.app
```

- `VERSION` is the single source of truth for `CFBundleShortVersionString` /
  `CFBundleVersion`. Change it there, never in `scripts/make-app.sh`.
- Info.plists are generated by heredocs in `scripts/make-app.sh` (mic usage string,
  `LSUIElement`). Edit the script, then rebuild — do not add a static Info.plist.
- No sandbox, no entitlements, ad-hoc signing locally. Direct distribution only.
- The ~550 MB models download on first launch and are cached in
  `~/Library/Application Support/WhoRealtime/Models`; tests must not require them.

## Rules

- Recording output goes to `~/Documents/Meetings` — never send it anywhere off-device.
  The on-device promise is a product constraint, not a preference.
- New UI strings: no localization system is wired up yet, so plain literals are fine;
  don't half-add `String(localized:)` in one view.
- Logging is unified `os.Logger` (`logger` in `SessionModel.swift`). No `print`.
- Do not add `Settings { … }` scenes. There is no settings window yet; see `TODO.md`
  before building one (`macos-settings-ui` skill has the template).
- Public API in `WhoRealtime` is consumed by the two executables — keep it `public`.

## CI / release

`.github/workflows/build.yml`: build + test on every push/PR, and on a `v*` tag build
universal (`arm64 x86_64`), sign, notarize, create the DMG, and publish a GitHub release.

Unsigned when no secrets are set. To sign/notarize add: `MAC_CERTS_P12_BASE64`,
`MAC_CERTS_P12_PASSWORD`, `APPLE_ID`, `APP_SPECIFIC_PASSWORD`, `APPLE_TEAM_ID`
(optional `SIGNING_IDENTITY`). Verify a real tag release, not just a green `main` run:
`spctl -a -vv`, `xcrun stapler validate`, `lipo -archs`.
